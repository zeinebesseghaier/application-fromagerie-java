# Application de vente – Fromagerie

Application de bureau en Java qui permet aux clients d'une fromagerie de consulter le catalogue, de remplir un panier et de passer commande.

Projet réalisé en binôme dans le cadre du BUT Informatique (SAE S2.01, IUT Paul-Sabatier, Toulouse, 2026).

## Fonctionnalités

- Catalogue des fromages avec images et type de lait
- Panier : ajout d'articles et gestion des quantités
- Commande avec choix de la livraison et calcul des frais de transport
- Génération et impression de la facture en PDF
- Données chargées depuis des fichiers JSON

## Technologies

- Java, Swing (WindowBuilder), Eclipse
- Bibliothèque org.json
- Conception UML
- Tests unitaires du modèle

## Organisation du code

- `src/main/java/ihm` : interface graphique
- `src/main/java/modele` : classes métier (Fromage, Panier, LigneCommande…)
- `src/main/resources` : données JSON et images

## Lancer le projet

1. Cloner le dépôt
2. Ouvrir le projet dans Eclipse
3. Exécuter la classe `MainP1.java`
